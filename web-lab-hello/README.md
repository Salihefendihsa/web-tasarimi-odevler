## 🛠️ Teknolojiler

- [Vite](https://vitejs.dev/) — Hızlı build aracı
- [React](https://react.dev/) — UI kütüphanesi
- [TypeScript](https://www.typescriptlang.org/) — Tip güvenli JavaScript

## 📦 Kurulum

```bash
# Repoyu klonla
git clone https://github.com/Salihefendihsa/web-lab-hello.git
cd web-lab-hello

# Bağımlılıkları yükle
npm install
```

## 🚀 Çalıştırma

```bash
npm run dev
```

Tarayıcıda [http://localhost:5173](http://localhost:5173) adresini açın.
